# 밴픽 오디오

제공된 `밴픽_사운드_Opus` 폴더의 스테레오 Ogg Opus 10개를 변환 없이 `public/draft-assets/audio/`에 복사했습니다. 2번 효과음은 별도로 제공된 `Downloads/2_맵_첫_선택.opus`로, 3번 효과음은 이후 별도로 제공된 `Downloads/3_맵_첫이후_선택.opus`로 교체했습니다. 전체 약 2.6 MB이며, 참가자 방 링크 진입 시 인증·사전 대기 단계부터 미리 읽고 디코딩하며 투표 화면에서도 같은 인스턴스를 재사용합니다. 운영 화면은 밴픽 패널 진입 시 미리 준비합니다. 준비가 끝난 AudioBuffer는 메모리에 보관해 클릭 시 추가 요청·디코딩·30ms 예약 대기 없이 즉시 시작하고, 결과 공개음만 애니메이션 시계 정렬을 위한 30ms 예약을 유지합니다. 외부 오디오 라이브러리는 추가하지 않습니다. 일반 안내·효과음은 60%, 2번 맵 첫 선택·3번 맵 재선택·8번 밴 클릭·9번 밴 확정 효과음은 각각 25%, 밴 BGM은 기존 12% 음량으로 재생합니다.

| 원본 번호 | 저장 이름 | 재생 시점 |
| --- | --- | --- |
| 1 | map-start.opus | 맵 투표·팟지 맵 선택 시작 |
| 2 | map-first.opus | 해당 단계의 본인 첫 맵 선택 |
| 3 | map-change.opus | 이후 맵 변경·재선택 |
| 4_and_10 | countdown.opus | 맵·밴 입력 마감 5초 전부터 반복 |
| 5 | map-complete.opus | 추첨 종료 후 확정 맵 카드 공개 |
| 6 | ban-bgm.opus | 밴 투표 중 반복, gain 0.12 |
| 7 | ban-start.opus | 밴 투표 시작, BGM과 함께 |
| 8 | ban-click.opus | 본인 밴 1~2개 선택 |
| 9 | ban-confirm.opus | 본인 밴 3개를 채운 선택 |
| 11 | ban-complete.opus | 최종 밴 결과 공개·다시 보기 |

`useDraftAudio`가 단계별 안내·BGM·카운트다운을 관리합니다. 서버 시각에 로컬 경과 시간을 더해 남은 시간을 계산하며, 새 스냅샷을 받을 때 카운트다운 음원을 재시작하지 않습니다. 단계 키로 안내음을 중복 방지하고 일시정지·연결 해제·음소거·방 이탈 시 현재 음원과 대기 중인 재생을 취소합니다.

선택 효과음은 본인의 입력에만 반응하며 서버 스냅샷 갱신·선택 해제·초기화에서는 재생하지 않습니다. 소리 켜기·끄기는 방 헤더에서 제공합니다. 진입 즉시 AudioContext.resume()을 호출해 자동재생을 시도합니다. 브라우저가 자동재생을 막으면 신뢰할 수 있는 클릭·키 입력으로 AudioContext를 활성화하고 현재 단계 안내를 재생합니다. 이미 재생을 허용한 브라우저에서는 바로 사용합니다.

최종 음원의 스펙트럼에서 확인한 네 공격부 시작점은 약 **240, 780, 1050, 1330 ms**입니다. `useDraftBanReveal`은 음원이 디코딩된 후 예약된 AudioContext 시작 시각을 기준으로 매 프레임 공개 개수를 계산합니다. 균일한 타이머 네 개를 사용하지 않으며 동작 줄이기 설정에서는 이동·확대를 생략합니다. 무음·디코딩 실패 시에는 로컬 시계로 공개하여 결과가 숨겨진 채로 남지 않습니다. 결과 음원의 로딩 대기는 최대 1초입니다.

로컬 Chrome에서 10개 음원의 디코딩과 실제 재생을 확인했습니다. 공개 프레임은 242, 786, 1053, 1335 ms로 측정됐습니다. 프레임 주기·오디오 출력 장치의 지연에 따라 실제 차이가 달라질 수 있습니다.

참고: [React 기본 훅](https://react.dev/reference/react/hooks), [Web Audio 재생 예약](https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode/start), [자동재생 제한](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay). `useAudio`는 React 기본 훅이 아니며 별도 라이브러리의 훅 이름으로 사용됩니다.
