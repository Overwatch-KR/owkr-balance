# 실시간 밴픽 화면 기준

확인일: 2026-10-20 (Asia/Seoul)

- [사용자가 지정한 선호픽/밴 변경 요약](https://gall.dcinside.com/mgallery/board/view/?id=overwatch2&no=1502458): 2026-06-17 게시글의 본문과 이미지 링크를 확인했다. 이 환경에서는 원문 브라우저 접속과 이미지 호스트가 차단돼 첨부 이미지를 직접 열지 못했고, 사용자가 제공한 화면 첨부를 배치 기준으로 함께 확인했다. 왼쪽의 작은 이름표·초상화와 가로로 나란한 역할별 영웅 격자를 참고했다.
- 2025년 `HeroBanPhase`·`BannedHeroesSelected` 이미지는 초기 도입 UI다. 이번 작업의 최신 화면 근거로 간주하지 않는다.

## 적용한 동작

- 기존 사이트의 surface/버튼/폰트/구분선 사용. 오른쪽 패널 제거. 저장·초기화·준비는 격자 아래.
- 역할별 격자 모두 4열. 같은 크기의 정사각형 초상화 사용. 공격 영웅 수에 따라 줄만 증가. 작은 화면에서는 이름을 접근 가능한 이름/툴팁으로 유지하고 격자 텍스트를 줄인다.
- 왼쪽 이름표 아래는 별도의 더 작은 고정 크기 초상화. 3→2→1순위 순서는 유지하되 이미지 위 숫자는 표시하지 않는다. 본인 선택은 저장 전에도 즉시 표시. 팀원은 서버가 제공하는 같은 팀의 표만 사용한다.
- 슬롯 선택·해제·순위 올리기 및 기권·저장·확정·오프라인 잠금 유지.
- 결과는 `heroResult.slots` 순서 그대로 표시. 첫 팀 1·4와 둘째 팀 2·3을 서버의 실제 team으로 연결. 공격 빨강/수비 파랑. 진영 미배정 맵은 A/B만 표시. 빈 밴도 순번 유지.
- 0.45초 간격으로 1→2→3→4 순차 등장. 같은 결과의 일반 상태 갱신은 연출을 재시작하지 않는다. 다시 보기 버튼과 reduced motion 지원.
- 개인 투표자 한 명을 최종 밴의 소유자로 표시하지 않는다. 팀 합산 결과이므로 선택 팀을 명확히 표시한다.
- 운영 제어·10인 접속/확정 현황은 버튼으로 여는 대화상자에서 제공한다. 운영자가 선수인 경우에도 본인 선택 화면을 유지한다.

## 범위

최신 게임에는 5번째 Lobby Ban이 추가됐으나 이 작업은 사용자의 UI 변경 요청이다. 현재 프로젝트 명세의 최대 4밴·선호 한 명·기존 봉인 및 집계 규칙을 변경하지 않는다. 새로운 규칙 도입은 별도 명세와 도메인 검증이 필요하다.

## 맵 흐름 추가 (2026-10-20)

준비 화면에서 투표/팟지 선수 직접 선택 방식을 적용한다. 팟지 선수는 공유 링크에서 검색·모드 필터·페이지로 미사용 맵 전체를 탐색하고 확정한다. 다른 참가자는 같은 화면에서 지정 선수의 선택을 기다린다. 맵 확정 후 영웅 픽창을 먼저 보여주지 않고, 확정 맵 이미지 전용 화면을 3초 유지한 뒤 선호 영웅 단계로 이동한다. 예제 경로의 `potg`, `potg-waiting`, `map-result`로 확인한다.
