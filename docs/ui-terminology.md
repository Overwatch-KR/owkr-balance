# 화면 용어 기준

| 개념 | 화면 용어 |
| --- | --- |
| 서비스 이름 | OWKR Match |
| 이번 내전에 등록한 사람 | 참가자 |
| 이번 내전의 사람 목록 | 참가 명단 |
| 팀 결과를 확인·조정하는 페이지 | 대진표 |
| 참가자를 팀과 역할에 나누는 작업 | 팀 배정 / 팀 자동 배정 |
| 코드로 명단·팀을 같이 수정하는 기능 | 함께 편집 |
| 읽기 전용 팀 결과 전달 | 결과 공유 |
| 준비·맵·영웅 밴을 진행하는 기능 | 밴픽 / 밴픽 운영 |
| 외부 계정 서비스 | 디스코드 / 디스코드 ID |
| 게임 계정 이름과 숫자 태그 | 배틀태그 |
| 탱커·딜러·힐러 구분 | 역할 |

투표·만족도 조사의 행동은 ‘참여’, 사람은 ‘참가자’로 표시합니다. 저장된 유저 시트 항목은 이번 내전 참가 여부와 별개이므로 ‘유저’를 사용합니다. 내부 타입·식별자·API 계약의 영문 이름은 화면 문구와 구분해 유지합니다.

이벤트 참여자 등록·조회 기능은 제거했습니다. 기존 `/event-participants` 주소는 대진표로 이동합니다. 기존 저장 자료는 자동 삭제하지 않습니다.
